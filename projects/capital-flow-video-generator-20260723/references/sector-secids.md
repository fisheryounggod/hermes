## API 域名差异
- `push2.eastmoney.com` — 部分环境无法访问（返回 HTTP 000）
- `push2delay.eastmoney.com` — 更稳定，本地测试环境可通
- 建议：优先 push2delay

## mainForce 字段说明
API返回的 mainForce 是原始元单位（如 6321804626），不是亿。
- 除以 1e8 转换为"亿"：`value / 1e8`
- 63亿 = 6321804626 元
