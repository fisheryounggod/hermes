# 雅思词汇21天计划 · 17天记忆法

> 改编自杨鹏《17天搞定GRE单词》的间隔重复原理，用21天学完 IELTS 核心主题词汇，再用45天复习巩固。
>
> 核心原理：通过8个复习周期（5分钟→30分钟→12小时→1天→2天→4天→7天→15天）在记忆衰减前及时复习，将短期记忆转化为长期记忆。

---

## 8个复习周期

| # | 周期 | 操作 |
|---|------|------|
| ① | **5分钟** | 遮住中文回忆词义 |
| ② | **30分钟** | 首次大复习，遮住回忆 |
| ③ | **12小时** | 晚复习，调换顺序克服干扰 |
| ④ | **1天** | 第二天复习+新学 |
| ⑤ | **2天** | 复习巩固记忆 |
| ⑥ | **4天** | 间隔延长，记忆深固 |
| ⑦ | **7天** | 一周关卡，抗遗忘 |
| ⑧ | **15天** | 长周期，永久记忆 |

**核心原则：宁可不学新词，也必须完成当天复习任务**

## 表2：每日学习流程（每主题约80-100词）

| 步骤 | 操作内容 | 周期点 |
|------|----------|--------|
| 1. 学习 | 看词 → 读音 → 说出中文 + 一个例句 | 约5分钟/10词 |
| 2. 复习 | 立即返回，遮住中文回忆词义和用法 | 30秒 |
| 3. 循环 | 每10词一组，学完即复习，循环推进 | 约25分钟 |
| 4. 大复习 | 整组结束前遮住中文全部过一遍 | 30分钟 |
| 5. 晚复习 | 当天两个主题全部词汇遮住中文过一遍，调换顺序克服干扰 | 12小时 |

---

## 三大核心原则

1. **再认即可** — 看词能说中文，不需要拼写
2. **例句记忆** — 每个词记一个例句，语境决定深度
3. **21天+45天** — 21天学完新词，45天复习巩固

## 时间分配建议

- **每天学习**：约2.5小时（早30分钟学新词，晚30分钟复习，白天碎片时间回顾）
- **每日任务**：2个新主题 + 交叉复习旧主题
- **总周期**：21天学完 → 45天巩固 → 每天3个List复习直至考试
