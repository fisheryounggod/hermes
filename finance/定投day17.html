持有 BOX
等于同时持有 b.watch
《定投改变命运》李笑来 · 附录 3《关于 b.watch》
一句话核心
从"赚价差"
变成"赚持有期间的持续分配"
b.watch 是 BOX 申购、赎回与交易的场所。它的收益不是自己涨出来的， 而是由持有 BOX 的人持续产生并定期发放的。
—— 李笑来《附录 3》
b.watch 是什么
定位BOX 的申购、赎回与交易场所
身份链上区块链 ETF 交易所
与 BOX 的关系BOX 是标的，b.watch 是场
  • 持 BOX = 同时与 BOX 共同成长，与 b.watch 共同成长
  • 双重身份：一边是资产价格，一边是承载交易与分发的"企业"
当前收入：两笔手续费
1%
BOX 赎回时缴纳的手续费
2‰
二级市场 BOX/USDT 交易对双向各 1‰，合计交易额
  • 这些收入的 50% 将定期发放给 BOX 持有者
  • "刚开始这个收入看起来并不多，经年累月……发展会非常惊人"
注意：这是"持续流量"，不是一次性卖出
未来收入：节点收益
  • EOS 节点收益
  • XIN 节点收益
作为节点需要一定储备，时机成熟时 b.watch 会启动节点收益计划； 超级节点产生收益时，除去成本之外，剩余收益将 100% 分发给 BOX 持有者。
—— 李笑来《附录 3》
企业价值到底在哪
本质赎回手续费的 5‰ + 交易手续费的 1‰
分配未来七年企业价值的 100% 在笑来课堂分配
形式按规则分发 b.watch 股份
  • 分发规则之一：BOX 的持有时间长度
  • 分发规则之二：BOX 定投任务的完成程度
  • 分发规则之三：笑来课堂的销售业绩
底层原理：把收益结构改掉
  • 传统定投的回报完全依赖价格：标的涨才有收益
  • 持有 BOX 则叠加了一条与价格无关的持续分配流：有人申购、有人赎回、有人交易，手续费就持续产生
  • 于是你从"赌一个终点价"变成"同时拥有终点价和过程现金流"
  • 持有时长越长、定投完成度越高、分发份额越多——行为本身被写进了分配规则
今日反思（自问清单）
  • 我的持仓回报，是只靠价格上涨，还是也有"持有期间就产生"的现金流？
  • 我的资产里，有多少是我长期持有的？短期波动会不会让我错过分配资格？
  • 我是否理解"赎回费""交易费"这类摩擦成本？如果完全没有，那是好事还是隐患？
  • 我选标的时，除了"会涨"，有没有考虑商业模式本身能否产生收入？
  • 如果我坚持定投 7 年，我的持有时长在收益分配上处于什么位置？
