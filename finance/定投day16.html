韭菜盒子
定投 BOX 的结构
《定投改变命运》李笑来 · 附录 2《为什么定投 BOX》
一句话核心
从"押注某个项目"
变成"押注整个行业发展"
当定投标的从单一项目（比如比特币）转换成一系列标的（比如 BOX）， 除了有效稀释机会成本之外，还等同于把赌注从"放到某个项目上" 变成"放到整个行业发展上"——这是降低风险到极致的靠谱方法论。
—— 李笑来《附录 2》
BOX 到底是什么
名称Btc + eOs + Xin，同时也是中文"盒子"
性质锚定"一揽子主流区块链资产"的区块链凭证（Token）
本质一个 管理费为零 的 ETF 产品
创始人李笑来本人也在定投 BOX
  • 江湖戏称"韭菜盒子"；"定投 BOX"被戏称"总吃韭菜盒子"
  • 申购与赎回在 b.watch 网站进行，可在二级市场用 USDT 直接买卖
成分表：10,000 BOX = 1 BTC + 1500 EOS + 8 XIN
50%
BTC 权重——2019.7 币种市占比 63%，长期必然被摊薄
4 : 1
EOS 与 XIN 在剩余一半中的权重比（XIN 占比略高）
要么主流资产，要么传销资产——定投者只能选主流
  • 2017～2018 的牛熊已教育市场：随便写白皮书就募资的项目"不堪一击"
  • 传销资产短期可能很赚钱，但不可能长期——定投者要穿越不止一个牛熊
三条护城河
01零管理费：不赚这一块钱的基金经理
02公开透明：持仓在 Mixin 公链上，随时可查
03无法随意增发：流通量可核对，杜绝"假份额"
  • 任何交易所上架 BOX，用户都能核对它有没有私自增发流通量——这是新手必须学会的一课
  • 赎回条件：市值超 10,000 美元收 1% 手续费；二级市场卖出双向各 1‰；或自己设定最早赎回时间（如三年后）
技术发展路线：为什么是这三个
可信账簿（BTC）→ 可信代码平台（ETH/EOS）→ 可信执行环境（Mixin）→ 可信硬件（？）
—— 李笑来，区块链技术发展的路线判断
  • ETH vs EOS：像 DOS 与 WINDOWS 的差别，EOS 是多线程的；且 BlockOne 是区块链世界资金最雄厚的公司
  • Mixin 的误解：Mixin Messenger 只是 Dapp，Mixin Network 才是公链
  • 路线差异：别的公链自下而上先造链再造 Dapp；Mixin 自上而下，先做非常好用的 Dapp（2017.12），再做公链（2019.2）
  • 投资成功的核心：投资行为契合发展规律，让趋势成为朋友而不是阻力
今日反思（自问清单）

  • 如果我只持有一个标的，我承担的是"标的风险"还是"行业风险"？我是否清楚二者的量级差异？
  • 我有没有能力判断一个资产是"主流"还是"传销"？我的判据是什么，还是只是看涨幅？
  • 我选择标的是否契合技术演进的内在逻辑，还是只在追热点？
  • 我的仓位结构里，有没有"管理费/摩擦成本"在悄悄侵蚀长期收益？
